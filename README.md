### Salut 👋, moi c'est Sylvain

Je développe des projets perso pour apprendre et pratiquer le développement full-stack et le déploiement.

### 🚀 Projets

- **[TemperatureApp](https://meteo.3dsr.fr)** : suivi des conditions d'un bureau (température, humidité, CO2, porte ouverte) avec saisie, historique et graphiques. Backend Go (`net/http`, PostgreSQL), front React + TypeScript, déploiement Docker automatique via GitHub Actions.
